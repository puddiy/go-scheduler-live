# Superdesign

Интерфейс проекта связан с [canvas Superdesign](https://superdesign.dev/teams/ebd691e4-2756-47aa-a67b-674507b14dc7/projects/ff7bd900-60a6-4353-8cec-a7317f18af46).
[Текущий макет](https://p.superdesign.dev/draft/a68e676c-4098-42cc-bb64-33cc8d246f1d)
содержит оформление реализованного UI и статичный снимок настоящей сцены.
Рабочее воспроизведение выполняет Pixi-плеер проекта по данным Go runtime/trace.

CLI запускается по требованию:

```bash
npx --yes @superdesign/cli@latest
```

Команда проверяет версию, авторизацию и доступные проекты. Если авторизация
истекла, выполнить `npx --yes @superdesign/cli@latest login`.

Локальный контекст хранится в игнорируемой Git директории `.superdesign/`:

- `init/` — шесть файлов анализа UI и зависимостей;
- `design-system.md` — палитра, типографика и правила интерфейса;
- `context-files.json` и `context-manifest.md` — выбранные UI-исходники;
- `resume.json` — проект, макет, версии и SHA-256 исходников для продолжения.

Проект Superdesign: `ff7bd900-60a6-4353-8cec-a7317f18af46`.
Макет: `a68e676c-4098-42cc-bb64-33cc8d246f1d`; версия 2 сохраняет исходный
скриншот, версия 3 — итерацию Gemini 3.1 Pro, версия 5 — реализованный UI
с согласованными значениями контролов статичного кадра. Версия 6 добавляет
реализованный инспектор G/M/P и навигацию по событиям.
RuntimeHeader зарегистрирован как переиспользуемый компонент.

Перед новой итерацией сравнить fingerprints в `resume.json` с текущими файлами
и обновить изменившийся контекст. Скриншоты и `--context-file` передаются
Superdesign; выбирать только нужные UI-материалы. Credentials в репозитории нет.
Генерация расходует кредиты; точные правки HTML через `import-design-draft --into`
сохраняют историю версий без новых generation credits.

После переноса оформления проверить `make ci`, production build, три браузерных
harnesses и реальные скриншоты. Макет не должен вводить очереди, stealing или
движения G/M/P, которые обычный Go trace не раскрывает.

Инспектор использует тот же `stateAt`, что и сцена. Выбор приостанавливает
плеер; одинаковые timestamp применяются вместе. История содержит последние
12 событий объекта до playhead, а раскрываемый JSON — нормализованный DTO,
не полный бинарный event и не внутренний runtime M.id. Queues и stealing
не выводятся из этих данных. Браузерный контракт инспектора включён в CI.

Проверка инспектора: **27/27**, включая Escape с фокусом на кнопке P;
финальный `make ci` содержит 166 frontend-тестов.
